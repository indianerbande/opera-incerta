# Release notes — 0.1.0-beta.1

**English** | [Deutsch](../../de/releases/0.1.0-beta.1.md)

Date: 2026-09-11 · Public source beta · Distributed as source

The first public release of Opera Incerta. It is the point at which the
project's documentation, licence, and contribution infrastructure caught up
with software that had been working for some time.

## What this release is

A local desktop writing application with a real library, a real editor, real
source control, and a real export — built and verified on macOS from source,
with the complete verification available to anyone who clones it.

It is a **source** release. No installer is published, and none has been
built.

## What it contains

**The library.** Markdown files on disk as the single source of truth; groups
as directories; front matter owned under one namespace with foreign keys
preserved byte for byte. Creating, renaming, reordering by dragging, deleting
into the desktop trash — and renaming never touches a file name. Page
categories per project. All four answers to opening a folder that is not a
project, including adopting one. A watcher that asks before unsaved work is
lost.

**The editor.** Formatting shown rather than spelled out, with markers
returning on the cursor's line: headings at their own size with the level in
the gutter, quotes, lists, task boxes, code, thematic breaks, and inline
emphasis. Front matter in an area of its own, read-only until asked
otherwise. Line numbers, zoom, per-sheet wrapping, a status bar. Find in the
open sheet from the native menu.

**Structure and search.** The outline of the open sheet. Search across the
library's text. Back and forward through the sheets you opened, and the ten
you saved most recently.

**Source control.** Status, stage, unstage, commit, push, fetch, pull, merge
with per-region conflict resolution, branches, publish, amend, `.gitignore`,
and discard — with a prose diff that shows changes word by word. Nothing
hidden.

**Export.** One Markdown file, or a PDF the application sets itself, whole or
from one sheet on. Groups become headings; front matter never appears. Four
supplied stylesheets, plus your own by duplicating one.

**Interface.** English and German, light and dark, eight accent palettes, a
packaged typeface, four resizable regions, and every action reachable without
a pointer.

## What this release deliberately does not include

- **Signed installers**, and no native package at all: `desktop:make` has not
  been run on any host. See the [platform matrix](../platforms.md).
- **Import** into an existing project. Adopting a folder as a new project
  works.
- **The AI assistant.** Fully specified, including the rule that without a
  connection it is unavailable and says so. Not implemented.
- **Snapshots**, and **DOCX and EPUB export**.
- **A formal accessibility conformance claim.** The rule — every action
  reachable without a pointer — is stated and checked; the standard is not
  claimed.

## Known boundaries

- Task boxes reach an export as the characters `[ ]` and `[x]`.
- A stylesheet cannot set the PDF's page margins or page numbers; the printer
  owns those.
- Conflict resolution decides per region, not within one.
- Reordering has no keyboard equivalent yet.

## Upgrading

There is nothing to upgrade from. Projects created by this release use a
`.opera-incerta/` directory whose format is documented in the
[specification](../../engineering/specification.md); a later release that has
to change it will say so and bring a migration.
