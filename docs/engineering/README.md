# Opera Incerta engineering documentation

These documents are the single authoritative engineering sources. They are
maintained in **English only**, deliberately: a product contract, a validation
rule or a dependency decision must not be able to diverge between two
translations. The public documentation that readers use is available in
[English](../en/README.md) and [German](../de/README.md).

- [Specification](specification.md) — normative product behaviour and
  architectural boundaries. What the application does, and why.
- [Testing and evidence](testing.md) — the evidence required before a claim
  about behaviour may be made.
- [Dependencies and update policy](dependencies.md) — purpose, licence, impact
  and replacement boundary of every external package.
- [Conventions](conventions.md) — the design and handling measures this
  project works by, carried over from earlier work.
- [Roadmap](roadmap.md) — open work only, and the decisions still to be taken.
- [Completed work](completed-work.md) — what was built, why it was built that
  way, how it was verified, and what it taught.

The working process around all of them — the invariants, the definition of
done, the commands that count as evidence — is in [`AGENTS.md`](../../AGENTS.md)
at the repository root.
